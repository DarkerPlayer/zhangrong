# 角色专属衣橱（2026-10-08）

衣柜的“单品”页默认打开当前角色的专属衣橱；“全部衣橱”仍保留所有角色的单品和通用库存。切换模型后重新默认显示该模型的专属单品。分类数量随当前范围变化，首次进入角色时优先显示有库存的分类。

归属依据依次为明确的 `sourceCharacterId`、准确匹配的 `sourceLookId`、没有前两项时的 `embeddedLookIds`。适配过某角色并不改变来源归属。旧单品没有来源信息时继续保留在全部衣橱，不猜测分配，也不删除。新上传并适配的单品保存创建时的角色和造型来源，重启后仍保留。

没有抽离独立部件的角色展示空态，可直接打开全部衣橱。整张立绘内的衣服仍然属于完整造型，不能伪装成可拆卸的独立库存。本次不新增任何角色部件图片。

完整造型仍按当前角色展示，已移除造型保留全局恢复入口。更换库存范围不会自动穿戴、切换角色或修改已保存的穿搭。跨角色适配与完整组合要求保持原状。

所有衣柜缩略图保留 `loading="lazy"` 与 `decoding="async"`；未选中的标签页和单品分类不挂载图片。

## 验证

- 专属来源隔离、通用物品、旧导入、新导入来源保存与重启。
- 默认专属、切全部、切角色恢复专属、有部件分类、无库存空态。
- 原配选择、跨角色适配、完整组合、恢复单部位、移除造型恢复等现有流程回归。
- 本模块的实际桌面预览与整体打包由主任务统一执行。
