# 1.6 语音低延迟更新

原先慢在两处：先生成整段WAV、再一次性交给播放器；空闲两分钟后关闭模型，下一次说话重新加载。文字回复快，并不代表语音已生成。

1.6沿用现有音色和模型，启用模型的增量音频输出。每约0.48秒音频生成完立即通过本机NDJSON流发送；界面在同一个Web Audio时钟上连续排程，后续片段生成与播放并行，不再等待整段。声音保持原速与音高，不靠加速播放冒充响应速度提升。

应用打开及选择音色后后台预热；运行期间保留当前音色模型。停止流式朗读发送协作取消，通常保留模型与参考缓存；无法正常取消时有两秒强制终止兜底。退出应用会释放模型。预热的代价是运行时保留模型内存，首次启动或切换音色仍可能等待几秒。
