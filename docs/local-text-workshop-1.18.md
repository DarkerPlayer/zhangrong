# 1.18 本地文本工坊

从 **女友 → 独立语言语料 → 文本工坊**，或 **朗读 → 文本工坊** 进入。粘贴一段文本，或者导入一本电子书，在本机整理成语料包。

## 两种提取方式

- **对白语料**：提取中文/英文引号内的句子以及明确的“人物：台词”格式，去掉相同短句的重复项并记录出现次数。用于挑选角色的表达参考。引号内也可能是引用、书名或其他内容，需在预览中筛选；没有明确人物标记时，不会凭空猜说话人。
- **阅读分段**：按原有顺序整理正文，每个片段最多 240 字。保留重复段落，适合保存成分段阅读文本包。可逐段试听，这一版不提供整本书自动连续播放。

预览会保留能从文件中获得的章节、页码或段落位置。长段落拆成多个片段，超过导入限制时明确报错，不会假装处理完整本书。

## 文件与限制

支持 TXT、Markdown、EPUB、DOCX、文字 PDF，以及此应用导出的 JSON 文本包。文本文件支持 UTF-8 和带 BOM 的 UTF-16；其他编码请先转换。EPUB 按阅读顺序读取章节，DOCX 读取正文段落和表格。PDF 使用应用携带的本地 PDFKit 组件，不需要安装 Office、Python 或额外语言模型。扫描 PDF、加密或受保护的电子书目前不支持提取；请先准备可选中文字的文件。

每个输入文件最多 20 MiB，提取文字最多 100 万字，每包最多 10,000 个片段。档案保存最多 30 个包，草稿最多 3 个，草稿保存一天。原始书籍不会进入聊天历史或浏览器的角色存档；包内容存放在本机文本库，界面按页读取。

## 分类、保存与角色使用

选中少量条目后可以运行 **本地 AI 分类**，沿用设置中的本地对话模型，每批最多 8 条。分类只整理用途标签，不改写原文，不猜人物身份。分类结果可能不准确，可直接修改每个片段的分类下拉框。可以停止；聊天优先，开始聊天时会中断正在运行的分类。没有启动本地模型时，规则提取、手动分类、查看、保存和导出仍然可用。

保存文本包后可再次打开，导出为 JSON 或 TXT。JSON 保留条目、分类与出处，可以重新导入；TXT 便于阅读及其他软件使用。删除包时移入本地文本库的回收目录，已加入角色的短句仍保留。

每位角色仍最多保留 40 条精选语料。加入前会检查剩余容量和重复内容，整批通过后才保存，避免挤掉旧条目。加入的语句属于表达参考及离线台词，不是重新训练模型；不会自动改变性格、身份、长期记忆或关系成长。可在原来的角色语料列表启停和删除，来源随条目保留。

文本解析和分类均在本机执行，不上传书籍。辅助分类依照 [Ollama Chat API](https://docs.ollama.com/api/chat) 的结构化输出接口，仍需人工检查分类是否符合使用场景。
