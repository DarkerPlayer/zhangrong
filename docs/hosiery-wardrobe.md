# 黑丝、白丝与渔网袜 · 2026-10-08

用户要求把已记录的三款袜子直接实现，并让最近新增角色都能使用。本轮覆盖温夫人、成年凌玉灵、梅凝、银月、紫灵、宋玉，共六位角色的八套现有造型，包含紫灵的紫衣、面纱和白衣版本。

## 单品与适配

| 名称 | 单品 ID | 分类 | 重点 |
| --- | --- | --- | --- |
| 黑色丝袜 | `sheer-black-stockings` | `hosiery` | 细腻半透明黑色织物与柔和光泽 |
| 白色丝袜 | `sheer-white-stockings` | `hosiery` | 白色织物与自然腿部明暗 |
| 黑色渔网袜 | `black-fishnet-stockings` | `hosiery` | 小菱格网纹沿膝盖、腿部曲线贴合 |

三件单品保存在 `public/wardrobe/items/`。单品参考图和各角色整身适配图分开保存，运行时选择完整匹配的造型，不能将几张整身图叠加。三款互相替换，按角色独立保存；恢复袜类时恢复该部位原配。其他单品也改变时，仍须有对应完整组合，否则进入已有适配流程。

当前角色自己的衣橱也展示明确分配给这六位角色的三款袜子；全部衣橱保留共享库存。分配不改变来源归属，也不把任意已有适配单品自动加入角色专属衣橱。
