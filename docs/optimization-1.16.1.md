# 1.16.1 优化验收

## 内存与资源

- 原创角色待机只加载原图和面部坐标；用户触发动作后才加载该动作组，最多同时读取、解码两张。动作完整就绪后再播放，切换请求、换装或卸载会取消旧加载；闲置或隐藏窗口 30 秒后释放纹理。
- 两套林薇造型原先各预载 17 张 1024 × 1536 图片，单套 RGBA 像素合计约 102 MiB。现在待机不请求这些动作图。此数为资源体积估算，不是实测进程 RSS 降幅；图片缓存、GPU、压缩和系统负载会影响实际内存。
- 写真模式仅挂载当前场景，使用自定义素材时不加载其它写真。静态资源和本地生成大图通过文件流输出，响应中止会停止读取。
- 播放器只提前解码约 5 秒音频，播放完成或取消即释放 PCM；取消也会唤醒等待缓冲的读取流程。
- 本机聊天请求的模型保留时间从 10 分钟减至 2 分钟；自启 Ollama 的默认保留时间同步为 2 分钟。语音仍按需启动并在空闲两分钟后退出。

## 衣橱与操作

- 左侧模型选择人物；完整造型列表限定当前人物，切换模型时清除旧搜索与筛选。Haru 有独立模型入口。
- 独立单品库存只列真实资产，按类别标明数量和适配状态；服装描述放入折叠的造型参考，不作为可穿单品。当前独立试穿仍以鞋履为主，并未新增通用衣服拆分或任意叠穿能力。
- 新增模型、为当前人物生成完整造型、上传新鞋履并适配分别有明确入口。修复上传新鞋履时误选已有库存鞋的问题。
- 已移除列表保持全局可恢复，全部造型被移除的人物也能找回；恢复操作不切换当前人物。静态写真移入背景页，明确其会进入写真模式。
- 不迁移或删除用户的人格、聊天、音色、已生成素材和穿搭状态。

## 语音：换音色复用模型，限制排队与缓存

2026-10-02 在本机 Apple M1 Pro / 16 GB / arm64，使用现有离线 Qwen3-TTS 0.6B 8bit、MLX Audio 0.5.6 测量。对照为修改前的本机成品服务，实验组为本次源码；两组都使用同一份模型、内置参考音色及一张已保存音色。按顺序执行，未并发运行推理，未下载模型或修改用户音色库，测量结束后关闭自行启动的全部语音进程。

| 场景 | 修改前首段 | 修改后首段 | 修改前全部生成 | 修改后全部生成 |
| --- | ---: | ---: | ---: | ---: |
| 进程冷启动，内置音色 | 4038 ms | 3031 ms | 7016 ms | 5919 ms |
| 同音色热态，不同文本 | 549 ms | 555 ms | 2326 ms | 2322 ms |
| 切到另一张已保存音色 | 3433 ms | 943 ms | 7585 ms | 5124 ms |
| 切回原音色，新的文本 | 3033 ms | 547 ms | 5738 ms | 3244 ms |
| 重播此前台词 | 530 ms | <1 ms | 2273 ms | <1 ms |

测量语料为三句固定中文短句：

- “今天辛苦了，先喝点水，我们慢慢说。”用于冷启动与切到另一音色。
- “休息一会儿吧，我会在这里陪着你。”用于同音色热态与最后重播。
- “窗外很安静，今晚也要照顾好自己。”用于切回原音色。

对应音频时长为 3.84、2.48、5.28、3.60、2.48 秒。这是服务侧首个 WAV 片段与全部生成耗时，不包含界面解码、音频设备或实际播放完成时间。每种情形仅测一轮，进程冷启动也会受到操作系统文件缓存与内核缓存影响，冷启动一行的差值不能归因于本次修改。同音色热态吞吐基本不变，主要收益来自省去音色切换时的模型重载，以及保留跨音色的已合成缓存。

对五组前后音频逐块去除 WAV 头，拼接 PCM 并计算 SHA-256，全部一致；包括四组新合成与最后重播。模型参数、参考录音、采样率、随机种子、0.48 秒分块间隔与播放速度保持不变。一次流程启动模型进程由三次降为一次；两分钟空闲仍结束进程，不恢复自动预热或永久驻留。

实现与回归覆盖：

- 服务最多保留一个正在执行的请求和三个待办；排队期间取消立即返回，关闭或图片生成前释放资源时取消整个队列。
- 每个请求传递自己的参考音色目录，一个进程复用模型权重；Python 最多保留三份参考录音及各自的编码缓存，按最近使用淘汰。重命名不清除编码，录音或参考台词变化会重算。
- 所有音色共享 16 MiB 音频 LRU；命中会更新使用顺序，切音色保留缓存，删除音色只使相应缓存与请求失效。已失效请求的迟到结果不会重新进入缓存。
- 真实子进程测试覆盖逐请求音色、流式取消、崩溃重启和空闲释放；轻量假模型测试覆盖有界队列、立即取消、关闭、资源重置、LRU 和删除失效。Python 参考缓存四项行为测试无需加载模型。

原始测量记录位于 `/tmp/muyu-voice-benchmark-results.json`，本机复测脚本位于 `/tmp/muyu-voice-benchmark.mjs`。记录仅保存场景名称、耗时、时长、片段数与 PCM 摘要；没有保存新合成的音频文件。
