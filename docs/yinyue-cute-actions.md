# 银月可爱动作（2026-10-07）

入口：衣橱选择「银月 · 银狐红绦」，主页点击「动作」。新增 16 项，原有变换重心、整理头发、恢复待机仍保留。

- 表情与小动作：轻轻眨眼、俏皮双眨眼、左眼 Wink、右眼 Wink、向左歪头、向右歪头、乖巧点头、轻轻摇头、困困闭眼、开心摇摆。
- 独立姿态：双手比心、指尖比心、狐爪卖萌、双手捧脸、掩嘴偷笑、抱抱尾巴。

每次点选播放一次并恢复待机。待机期间会偶尔播放双眨眼、左右歪头、点头或摇摆，手动互动可以打断。左右 Wink 按角色自身左右区分。

10 个小动作使用现有立绘的网格与眼睑动画；6 个手势使用独立透明姿态图，按准备、姿态、恢复阶段淡入淡出，并非连续骨骼动画或视频。姿态帧保留各自表情，播放时关闭额外眨眼和说话口型叠加。抱尾巴使用全身构图。

原始待机立绘、音色和衣橱配置保留。新动作只对当前银月造型开放；新衣服需要另行适配姿态资源，不能直接套用旧衣服的手势图。
