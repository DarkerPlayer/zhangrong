# 本地人物与换装工作台

用户已要求实现一个适合 M1 Pro、16 GB 统一内存的本地版本：上传少量人物照片，生成可以使用现有动画效果的角色，以及衣服、高跟鞋等衣橱成品。

## 使用流程

衣柜提供“本地生成”入口。新人物接受最多三张参考图和文字说明；现有人物可以生成新套装，或使用鞋履参考图生成合身成品。首版默认 512 × 768，另提供 768 × 1152。任务完成先显示图片和动画坐标预览，允许校正五官位置，用户点击加入衣橱才登记。失败可以查看原因和重新提交；取消立即终止生成进程。关闭面板后任务仍可查询，应用退出后未完成任务标为中断。

## 引擎与资源

使用 Apple Silicon 的 MLX/MFLUX 和 FLUX.2 Klein 4B 预量化 4 位权重。Python 和模型安装在用户 Application Support 的独立目录，首次安装可以联网下载公开依赖和模型；照片与推理均在本机处理。安装版本和模型修订固定，生成过程中不得自动下载其他大型模型。

运行单任务、四步推理，缩小参考图，使用低内存和分块 VAE 解码。生成前停止应用当前的语音请求，卸载应用使用的语音和聊天模型；生成期间相关请求返回清晰的忙碌提示。每次生成使用独立子进程，结束或取消后进程退出释放模型。安装下载不占用推理资源，不必阻止普通对话。

## 接口与保存

`GET /api/studio` 返回安装状态、当前任务、任务历史和用户目录。`POST /api/studio/setup` 启动安装；`POST /api/studio/jobs` 创建任务；任务路径的 `cancel` 和 `import` 执行取消与登记。状态为 queued、running、preview、imported、failed、cancelled。

上传使用经过校验的 PNG/JPEG/WebP，每张最多 8 MB，最多三张。服务生成不可预测的 ID，界面不得指定任意路径。成品图片、rig、来源及元数据原子保存到 `~/Library/Application Support/沐语/local-studio`。素材只从受限静态路径提供；接口不返回参考图片的 base64 或内部绝对路径。

用户目录追加到既有目录：新人物登记新的 character 和 look；新套装绑定原 character；鞋履适配登记 item 与 look/item fit。生成成品不继承原图的下蹲和走路动作，避免换装时出现旧衣服；沿用呼吸、眨眼、头部和口型动画。前端先加载本地目录再恢复保存的角色选择，重启后保持本地人物和鞋款。

## 成品校准

macOS Vision 去背景并提取脸部五官，按这张输出图片生成 rig。必须检测到合理的人脸，不能静默套用其他人物的五官位置；肩部采用保守估计并保持 armMobility 为 0。预览允许用户调整坐标；登记时验证坐标有限且在合理范围内。

## 验证

运行任务服务和 API 测试：上传限制、串行任务、失败、取消、重启、登记、路径隔离和资源释放。运行界面测试：上传、预览、确认导入、错误与持久恢复。完成一次真实本地推理并记录时间、内存口径、PNG/rig 和截图；全量现有测试、生产构建通过后更新桌面版。安装或模型受外部服务阻碍时如实保留可用界面与诊断，不把模拟结果当作真实推理。
