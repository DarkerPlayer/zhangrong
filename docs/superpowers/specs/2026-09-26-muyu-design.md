# 沐语 本地桌面陪伴设计

用户目标：参考 DOCX 中的夜景写实桌面女友，实现可以本地运行、换装、对话和陪伴的成品。用户明确要求不提问，设计与实现细节自行决定。

参考原作是生成的视频，未提供视频原文件。交付使用原创成年虚构人物场景，加轻动态、换装过渡和可导入的本地循环视频，不声称支持逐帧生成真人动作。所有内置素材保存在项目内。界面采用夜景全屏、左侧轻量导航、逐字字幕、底部对话输入，突出人物。

功能：四套造型，文字聊天，系统中文朗读，本地 Ollama 真实模型（可用时默认使用）和明确标识的内置互动，专注计时，雨声，回忆记录和导出，设置与持久化，本地媒体导入，桌面置顶、小窗和全屏。

架构：React/Vite 前端；Node 原生 HTTP 本地后端；Electron macOS app。默认仅 loopback，无云端账号或密钥。偏好与聊天存在 localStorage，自选图片/视频存在 IndexedDB。Ollama 仅调用 127.0.0.1。不改系统壁纸，不自动读取屏幕。

验收：构建通过，核心自动化测试通过，页面与桌面应用实际启动，换装/聊天/设置/计时器/记录/导入等交互验证，小屏布局无溢出。一键启动脚本及可直接打开的 .app，README 说明功能与局限。
