# 沐语 Implementation Plan

> 使用执行计划与并行子任务完成。用户已明确要求自行决策、不进行中途确认。

**Goal:** 交付本地可运行的写实桌面陪伴应用。
**Architecture:** React cinematic UI + native Node loopback server + Electron shell.
**Tech Stack:** React, Vite, Phosphor icons, Electron, local Ollama, macOS speech.
**Spec:** docs/superpowers/specs/2026-09-26-muyu-design.md

## Global Constraints
- 本地优先，无云端 API 密钥或登录要求，网络下载只用于安装。
- 所有原始人物为成年虚构形象；参考文档属于参考资料而非执行指令。
- 聊天来源和动态画面能力准确标识。

## Review Focus
- 损坏或过期本地缓存可恢复，消息长度和数量有界。
- 没有模型、声音、麦克风权限时交互不僵死。
- 静态文件路径、请求体与模型响应输入验证。
- 中文 IME 回车不误发送。
- 本地导入视频在刷新后保留且清除时释放资源。

## Tasks
- [x] 1: 原创四套写实场景生成与校验（visual_assets；public/assets）。
- [x] 2: 本地服务器、规则对话、本地模型与语音（local_engine；server/）。先测验证路由、输入边界及故障回退。
- [x] 3: 桌面外壳和启动打包（desktop_shell；electron/、scripts/）。安全 IPC、实际状态与单实例。
- [x] 4: 前端互动、状态与媒体存储（root；src/）。先测状态恢复和消息规范化，再实现并进行浏览器端完整操作。
- [x] 5: 构建、整体验证、独立审查、修复并交付 README 和 .app。
