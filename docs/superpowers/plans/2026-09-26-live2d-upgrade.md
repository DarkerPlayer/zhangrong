# 沐语真实动态桌宠升级

用户反馈：现有照片镜头运动不够，要像萌宠一样真正会动，接入 GitHub 项目；延续无需中途询问、直接完成的授权。

选型：pixi-live2d-display 0.4.0 + PixiJS 6.5.10；本地 Cubism Core 和 Haru 样例角色。AIRI 的 Live2D 也采用该渲染器；整套迁移 AIRI/Open-LLM-VTuber 会重复现有本地聊天后端。保持原有聊天、记忆、专注、离线模型和原照片模式。

执行：
1. renderer 子任务接入真实骨骼动作、眨眼、呼吸、目光跟随、点击互动；本地资源与归属说明。
2. native 子任务加入可拖动透明桌宠模式，切换正常窗口时恢复状态。
3. dialogue 子任务新增动作指令，能力说明与实际渲染一致。
4. 主任务整合动态场景、互动按钮、音频振幅口型、模式切换与透明桌宠界面。
5. 自动测试 + 实际浏览器/Electron 渲染验证 + 多帧动作证据，修复后构建桌面成品。

进度：研究完成；1–4 完成；5 自动测试 59/59 通过；真实动画/口型、透明像素、真实拖动和窗口还原验证通过；最终桌面包已重新生成。

实现约束：真实局部形变而非照片缩放；所有运行资源本地；保留数据与原照片模式；模型和 Cubism Core 授权独立于 MIT 渲染器；不声称真人视频生成。
