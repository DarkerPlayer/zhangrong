# 沐语 1.4 参考音色

设置 → 声音与画面 → 试听音色。聊天朗读与口型沿用同一语音模块，全部角色使用本次录音参考音色。

参考为用户提供录音开头的 5.4 秒普通台词，文字为“老板，这是昨天下午的会议记录。”完整原始 MP3 不进入应用包。参考片段和模型均保存在本机，不向远程服务发送录音、文本或生成声音。

本机使用 MLX Audio 0.5.6 与 Qwen3-TTS-12Hz-0.6B-Base-8bit，模型 revision 为 50f45ef0047cde7e84c2ef04326acb8ada2436a7。模型、Python 与依赖随应用内置，强制离线加载。授权说明见 `.runtime/voice/LICENSES.md`。

M1 Pro 16GB 上首次生成约 6 秒问候音频耗时约 13 秒。长度、机器负载与模型加载影响延迟；相同文字在进程内有缓存。两分钟空闲后释放语音模型，下一次需要重新加载。声音是参考复刻效果，语调和细节可能与原录音有差异。

停止朗读会取消当前生成；正在生成时显示“正在准备声音”。配置损坏或生成失败会提示错误，不会悄悄换回系统声音。聊天语音只在内存中生成，不写入音频历史文件。

示例：`docs/audio/reference-voice-preview.wav`。合成台词“你好，我是沐语。今天过得怎么样？我会在这里，慢慢听你说。”已用本地 ASR 核对。ASR 仅用于开发验收，不进入成品包。

自动检查：102 项通过，涵盖排队、取消、超时、崩溃后重启、关闭、失败提示及试听入口。

成品验收：1.4.0 独立 macOS 应用打包成功；本机健康接口返回 reference / available；成品接口成功输出 24kHz 单声道 WAV；原生界面已显示准备声音及正在说话状态。包内仅包含参考 WAV、配置、模型、Python 与授权文件，没有完整来源 MP3 或开发用 ASR 模型。全部文件链接已检查为包内路径。
