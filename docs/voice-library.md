# 母狗张容 1.5：本地音色库

应用名为“母狗张容”，虚拟成年陪伴角色名为“张容”。衣橱保留原有外观主题与服装名称，切换穿搭不会改变角色的自称。

## 添加与使用

1. 点击侧栏「朗读」进入独立朗读工作台。上方用于试听与保存语料，下方「音色管理」管理所有女友共用的音色卡。
2. 选择 MP3、WAV、M4A 等浏览器支持的音频，最大80MB。
3. 听原录音，设置起点与3–20秒的片段时长，建议单人清晰讲话6–12秒。
4. 填写音色名称。台词留空会在本机自动识别；也可填写与片段逐字一致的台词。
5. 点击“制作并保存音色”，成功后音色库和上方的朗读音色选择中都会出现新卡片；保存不会自动改变任何女友的声音。每张卡都可以直接试听或改名。
6. 打开侧栏「女友」，在「专属音色」中选择共享卡片。选择只保存在当前女友本体中，切换女友后会使用她自己的选择。
7. 女友页每条自定义语料及内置表达示例都有「试听」。试听使用当前女友选中的声音；`{personaName}` 与 `{userName}` 分别替换为人格名和当前人格记忆中的称呼，其他文本按字面朗读。
8. 在朗读工作台选音色、输入最多 240 字并试听；可在合成中随时停止。点“保存语料”后，内容只写入当前女友，并记住这次选择的音色；以后重播仍使用该音色，不会改动女友的默认音色。

支持多个音色、改名和删除。正在被任一女友或已保存语料使用的音色不能删除；先为相关女友更换默认声音，并处理引用它的语料，即可删除。这样不会让其他女友的绑定或语料静默失去原音色。内置参考音色始终保留。名称相同的音色也独立保存；内部使用随机ID，不会互相覆盖。音色制作是保存录音参考与对应台词，不需要重新训练模型。

试听卡片不会修改女友的音色绑定，也不会写入旧版音色库的全局选中记录。聊天与试听都通过 `/api/tts` 的 `voiceProfileId` 明确指定本次声音；不同音色的合成顺序执行，停止或切换后不会播放过期请求的声音。

## 保存与隐私

音色保存在 `~/Library/Application Support/沐语/voice-library/`。为兼容旧版，数据目录与 muyu://app 地址保持不变，原聊天、衣橱、称呼和设置继续可用。桌面入口已改名。

只保存所选短片段及台词，不复制完整源录音。新增音色、台词识别和声音合成均在本机完成。模型与 Python 环境已随应用内置，强制离线加载。无云端账号或API密钥要求。

音色库独立于应用包，升级或移动应用不会覆盖它。生成聊天声音只保存在内存；首次朗读仍可能需要十几秒。当前版本在需要朗读时加载模型，以流式方式边生成边朗读；空闲两分钟后退出语音模型进程，下一次未缓存的朗读会重新加载。打开应用或管理音色卡不会自动加载模型。

## 实现和验收

- Qwen3-TTS-12Hz-0.6B-Base-8bit + MLX Audio 0.5.6。
- Qwen3-ASR-0.6B-4bit，用于短片段台词自动识别。
- WAV先在界面解码、裁剪为24kHz单声道PCM16；服务端检查格式、时长、大小和静音。
- 原子保存、顺序执行音色库修改；失败或取消不会保留半成品音色。
- 音色切换会停止旧声音并清除合成缓存，避免串音。
- 105项自动检查通过；实测自动转写、创建音色、选中后重建服务恢复、使用新增音色合成普通问候成功。

示例：`docs/audio/zhangrong-voice-library.wav`。第三方授权与模型修订号见 `.runtime/voice/LICENSES.md`。

原生应用验收：在1.5.0的文件选择器中导入参考WAV；默认截取5.4秒，台词留空；成功自动转写并显示新卡片；点击使用后，设置显示新的音色名称；试听进入准备声音状态。桌面快捷入口已更新，原用户称呼与所选衣橱外观正常保留。
