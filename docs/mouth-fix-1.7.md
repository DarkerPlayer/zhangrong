# 1.7 嘴部表现修复

原版原创立绘说话时，先用单一肤色盖住原图嘴巴，再绘制椭圆嘴腔、通用牙齿与舌头。这会抹掉人物自己的唇形、肤色光影与嘴角，并让不同人物出现相同的卡通嘴。

本次移除这一覆盖层。现在用局部纹理变形保留原图唇纹、唇色与已有细节，嘴角渐变固定，嘴唇只做克制的伸缩和微小位移。静音时使用原图采样，不给整张图片增加坐标重采样误差。

音频到口型只做一次按毫秒计算的平滑，不再先按帧平滑、再在角色上平滑。低噪声保持原始表情；开合上限0.7，停顿约0.3秒内回到静止，避免大张嘴与拖尾。

适用所有22套原创立绘，共用同一个渲染器。Haru仍使用自己的Cubism口型参数。语音流式生成、音色库、衣橱、人物选择和历史记录保留。

验证：113项自动测试通过；在WebGL中使用相同原图和相同0.65信号对比修复前后，检查绯月、栀夏、阿玛拉、樱奈四种不同脸型与肤色。图片：`docs/screenshots/mouth-comparison-1.7.png`；局部对比：`docs/screenshots/mouth-detail-1.7.png`。

这一方案属于2D立绘的轻微唇部动态，仍不具备逐音素生成真实口腔和牙齿的能力。

成品验收：1.7.0已打包启动，原生应用朗读时进入“正在说话”，人物保留原有唇形，无椭圆口腔覆盖；当前绯月造型和用户设置正常保留。
