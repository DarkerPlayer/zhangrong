## 使用方式

1. 进入衣橱，选择角色，打开“单品”。
2. 在发型、连身装、鞋履、指甲颜色、手表或耳环分类中选择单品。
3. 原来源造型标记“原配”；其他角色首次使用时点“适配到当前角色”。生成预览确认后加入衣橱。
4. 已生成的完整组合可以直接切换。卸下替换单品使用“恢复原造型…”；如果其余单品组成的组合还没有生成，则先生成恢复结果。
5. 上传新单品也可选择这些分类；导入后进入共享库存，其他角色可以继续适配使用。

“恢复原造型”撤销某个部位的替换。例如只恢复鞋履会保留已选择的发型与甲色。它不等于从原始立绘中擦除原本画好的服装或配饰。清空完整穿搭继续使用当前人物已有的白色比基尼底装；没有底装的角色保留当前外观。

## 组合与保存

- 每张适配结果记录 `lookId`、完整 `selection`、图片与 rig。键由规范化的分类及单品 ID 生成。
- 只使用完全匹配的组合；不存在时保持当前外观，不用另一个角色或其中一件适配图替代。
- 开始生成时保存当前组合的参考图快照。换发型只允许发型变化；甲色不需要额外图片；恢复某个部位同时参考当前组合及原始造型。
- 导入返回完整 `importedSelection`，包括恢复原配的空对象。旧版单件鞋履结果仍然兼容。
- 选择按外观角色保存，女友之间仍有独立的外观记录。生成结果持久化于原有本地工作室目录。
- 更换后的立绘关闭原造型专属动作关键帧，避免播放动作时突然变回原来的穿搭。
