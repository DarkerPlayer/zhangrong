## 直接打开

双击 **release/母狗张容.app**，或双击 **启动母狗张容.command**。桌面也会放置应用入口。

成品包含运行环境、素材、Ollama 和 Qwen2.5 1.5B 本地模型，无需 API Key、账号、Node.js 或额外模型下载。可将整个 `.app` 拖进“应用程序”文件夹。构建针对这台 Apple Silicon Mac 验证。

## 可以做什么

- **动态角色**：13 位原创伙伴均设定为 26–30 岁的成年女性；林薇有象牙白交叉高领上衣配黑裙、白衬衫配酒红职场裙两套造型，每套都有服装匹配的优雅下蹲和四帧高跟鞋走姿；美杜莎有金枝王冠造型；也可选回 Haru。移动鼠标、点击头部或互动按钮可触发回应，可以直接说“摸摸头”“挥挥手”“害羞一点”；选择林薇时还能说“下蹲”或“走两步”。
- **透明桌宠**：点右上角“桌宠模式”，变为透明置顶小伙伴；按住顶部点阵拖动，点右上角返回完整窗口；点“聊天”展开输入框。顶部衣架按钮打开桌宠衣橱弹层，可搜索、筛选并切换 25 套原创造型；点空白处、关闭按钮或按 Esc 收起。
- **女友本体**：从侧栏“女友”进入人格工作台。三位内置女友各有独立语言特色，可改名、切换三档亲密程度、添加分类语料、复制为自定义人格，并分别选择音色。
- **陪伴**：文字自由对话、逐字字幕和本机中文语音朗读。聊天请求只携带当前女友的人格快照、记忆和最近 24 条对话；切换女友会中止旧回复，避免串线。
- **衣橱**：完整窗口的“衣橱”只管理画面外观，提供 25 套原创动态造型、Haru 原始造型，以及日常、约会、居家、婚纱四套旧版图片场景。外观选择会保存在本机，但不会改变女友的人格、语料或聊天。
- **桌面小窗**：右上角切换小窗和置顶；点“沉浸模式”隐藏界面，按 Esc 返回。
- **专注**：15 / 25 / 45 / 60 分钟倒计时，支持暂停、恢复、重置和轻柔雨声。
- **回忆**：最近 200 条消息保存在本机；收藏独立保留，不会随滚动历史自动删除。可导出文本备份。
- **自定义画面**：衣橱中导入 JPG、PNG、WebP、GIF 或 MP4 / WebM 视频。支持静音循环播放，刷新后保留，单个文件不超过 150 MB。

原生菜单“陪伴”也提供快捷键：桌宠 `⌘⇧P`、置顶 `⌘⇧T`、小窗 `⌘⇧M`、全屏 `⌃⌘F`。`⌘K` 聚焦聊天输入框。

## 女友本体与外观的边界

- 人格本体决定名字、年龄、关系身份、说话节奏、调侃方式、亲密语料、记忆和音色。
- 外观只决定当前显示的立绘、服装、动画能力与背景。切换外观不会改变当前女友，也不会切换她的聊天、语料或声音。
- 本地模型收到的外观信息明确标为“画面”，不能覆盖人格身份；自定义语料只是有数量上限的风格参考，不能覆盖能力和安全规则。
- 三位内置人格都设定为 25 岁以上的成年女性；“年下”表示成年恋人之间的年龄差，不是妹妹或未成年人设定。

25 套原创造型是内置 ImageGen 生成的完整 2D 人物立绘，每套配有面部与身体坐标文件。PixiJS 在本机对立绘做局部网格形变，产生轻微转头、呼吸、摆动与目光回应；面部着色实现眨眼与口型。原有六套支持小幅摆臂；1.3 新增十六套以及 1.8、1.9、1.11 新增的美杜莎与林薇造型均以点头、歪头和微笑回应招呼，不做独立手臂挥动。1.10 为林薇的酒红职场造型增加下蹲姿势和四帧红底高跟鞋走姿；1.12 为象牙白通勤造型制作对应的独立动作图。它们不是 Cubism 模型，也不是 Haru 的贴图换色。切换造型会载入对应的完整原创立绘与坐标。雪乃的洛丽塔造型指成年人的服装风格；阿玛拉是受加纳文化启发的虚构成年公主，不代表真实王室人物。

保留的 **Haru · 动态陪伴** 使用真正的 Live2D Cubism 模型，包含五套预制动作、八种表情、自动眨眼、物理摆动与目光跟随。Haru 原始贴图未因新增穿搭而修改。

两种动态实现的口型都根据本机朗读音频的实时振幅开合，并非精确的逐音素口型；动作来自已有程序或模型预设，不能按文字生成任意新动作、自由行走或真人视频。长裙、宽袖与披肩仍是二维画面中的服装，没有独立布料模拟或任意角度的三维转身。旧版四套图片场景与导入图片/视频仍单独保留，图片的轻动态只是镜头移动。完整素材与坐标清单见 [docs/wardrobe-expansion.md](docs/wardrobe-expansion.md)，最初六套素材的记录保留在 [docs/glam-assets.md](docs/glam-assets.md)。

自由聊天默认使用本地 Qwen2.5 1.5B；它是体积较小的模型，复杂推理能力有限。模型不可用时会明确提示并回退到内置场景互动。内置互动采用预设规则，不假装是大模型。

1.4 中文朗读使用所提供录音的参考音色，在本机通过 Qwen3-TTS 合成。1.15 起在“女友”人格页管理音色，每位女友记住自己的选择；缺失音色只会让该女友回退到内置音色。首次生成约需十几秒，界面会显示准备状态。录音不上传，模型已内置。详见 [参考音色说明](docs/reference-voice.md)。麦克风输入取决于浏览器语音识别支持，可能需要联网；不支持或拒绝权限时仍可用键盘。应用不会自动读取桌面、屏幕、相册或其他个人文件。

## 数据与退出

人格、聊天、收藏、称呼、偏好和音色选择均保存在应用的本机存储中；导入画面保存在本机 IndexedDB。每位女友的数据独立，导出和清空只作用于当前女友。桌面版与浏览器版的数据各自保存，不自动同步。

首次打开 1.15 时，旧版全局聊天、收藏、称呼和语料会迁移为一个独立的“张容”自定义人格；旧衣橱外观设置会原样保留。迁移只写入新的 `muyu-state-v2` 存储，不会覆盖旧的 `muyu-state-v1` 数据。

关闭原生窗口或按 `⌘Q` 退出应用，会关闭由它自行启动的服务；不会结束其他应用启动的 Ollama。

## 浏览器备用方式

在项目文件夹执行 `npm start`，访问输出的本机地址（默认 `http://127.0.0.1:4317`）。`npm run stop` 关闭该脚本启动的后台服务。普通使用推荐直接打开 `.app`。

## 开发

构建需要 Node.js 22.12+（或 20.19+）。本机已有系统 Node 18，使用仓库的双击脚本会自动优先选择可用的新运行时；不要用旧 Node 执行 Vite 构建。

```sh
npm install
npm run build
npm test
npm run desktop
npm run build:desktop
```

- `src/`：界面、状态、媒体与音频。
- `server/`：本机聊天、语音和静态资源接口。
- `electron/`：桌面窗口、原生操作、本地模型进程。
- `scripts/`：启动、退出、打包和模型安装工具。
- `public/assets/`：四套原创场景。
- `public/looks/`：25 套原创人物 PNG、逐套配置的 `rig.json`，以及随应用打包的来源说明。
- `public/live2d/`、`public/vendor/`：完整本地 Live2D 角色、动作、表情、Core 与许可证。
- `.runtime/ollama/`、`.runtime/models/`：本地模型资源。
- `docs/asset-prompts.md`：图像生成提示词及来源记录。
- `docs/glam-assets.md`：1.2 最初三位成年角色、六套穿搭的素材路径与创作描述；不作为逐字提示词记录。
- `docs/wardrobe-expansion.md`：角色与造型清单、图片/坐标路径与来源链接。
- `docs/wardrobe-model-workflow.md`：后续新增人物模型的可复用制作与接入流程。
- `docs/wardrobe-asian-prompts.json`、`docs/wardrobe-world-prompts.json`：1.3 新增 16 张图片的逐字提示词、生成/编辑模式、参考图和原始生成文件路径。
